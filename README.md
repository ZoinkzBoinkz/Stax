# Stax
Supplement scheduler

Live: https://zoinkzboinkz.github.io/Stax/

- `index.html` is the built site (what GitHub Pages serves).
- `supplements.json` is the dataset: supplements, forms, rules, limits and sources.
- `src/template.html` is the page source; `python3 src/build.py` inlines the dataset and writes `index.html`.
